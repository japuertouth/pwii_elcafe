CONTENIDO INFORMATIVO

Curiosidades del café

Consulta y administra las publicaciones registradas.

Endpoint: GET /api/curiosidades?categoria_id=&region_id=&q=&page=&limit= · Filtros: GET /api/categorias?tipo=curiosidad y GET /api/regiones
TítuloCategoríaRegiónAutorAcciones
Aquí se mostrarán las curiosidades registradas.

Campos basados en la tabla curiosidades: titulo, categoria_id, region_id y creado_por. Los nombres de categoría, región y autor se obtendrán mediante sus relaciones.

DETALLE DE PUBLICACIÓN

Detalle de curiosidad

Endpoint: GET /api/curiosidades/:id · Eliminar: DELETE /api/curiosidades/:id

Vista de los campos que se mostrarán para una curiosidad seleccionada.

Título
Se obtiene de titulo
Descripción
Se obtiene de descripcion
Categoría
Se relaciona mediante categoria_id
Región
Se relaciona mediante region_id (opcional)
Autor
Se relaciona mediante creado_por (opcional)
Fechas
creado_en y actualizado_en

ADMINISTRACIÓN

Crear curiosidad

Formulario basado en los campos reales de la base de datos.

Crear: POST /api/curiosidades · Editar: PUT /api/curiosidades/:id

El autor se determina desde el usuario autenticado (campo creado_por); no se solicita escribirlo manualmente. Las fechas las gestiona el backend.

ADMINISTRACIÓN

Editar curiosidad

La pantalla utiliza los mismos campos que el formulario de creación y carga los valores actuales mediante GET /api/curiosidades/:id.

COMUNICACIÓN

Formulario de contacto

Formulario público para visitantes de la Fan Page.

Endpoint: POST /api/contacto

Si el visitante inició sesión, el backend podrá asociar usuario_id. Si no, quedará NULL. El estado leido inicia en 0 y creado_en lo asigna el backend.

SOLO ADMINISTRACIÓN

Bandeja de mensajes

Mensajes recibidos desde el formulario de contacto.

Listar: GET /api/contacto · Marcar leído: PATCH /api/contacto/:id/leido · Eliminar: DELETE /api/contacto/:id
NombreCorreoAsuntoMensajeEstadoFecha
Aquí se mostrarán los mensajes recibidos.

Campos de mensajes_contacto: nombre, correo, asunto, mensaje, usuario_id, leido y creado_en.
