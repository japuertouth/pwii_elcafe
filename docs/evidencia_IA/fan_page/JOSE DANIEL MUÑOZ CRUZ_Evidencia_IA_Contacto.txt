Prompt 1:
“Revisa mi página de contacto para el proyecto Café Hondureño. Quiero que tenga un diseño moderno, ordenado y que combine con el tema de café. Manten el HTML, CSS y JavaScript en archivos separados.”

Prompt 2:
“Ayudame a organizar la pAgina de contacto con un encabezado y menu de navegación, información de contacto y un formulario. Usa tonos oscuros con detalles dorados y que se adapte a celulares.”

Prompt 3:
“Revisa el JavaScript del formulario para validar que los campos obligatorios esten completos y que el correo tenga un formato valido. Tambien quiero un boton para cambiar entre modo claro y oscuro.”

Prompt 4:
“Indicame como enlazar contacto.html desde la página index.html sin modificar los estilos ni el JavaScript que ya usa Inicio. Guarda los estilos y la lógica de Contacto en archivos independientes.”

Uso de la IA:
Se utilizó como apoyo para proponer la estructura, revisar la validación del formulario y separar los archivos de Contacto. Después se revisaron los enlaces y la organización del proyecto para integrarlo con Inicio.
