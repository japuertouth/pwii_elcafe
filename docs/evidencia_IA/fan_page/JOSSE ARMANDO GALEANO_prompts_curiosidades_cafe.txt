============================================================
EVIDENCIA DE USO DE INTELIGENCIA ARTIFICIAL (IA)
Proyecto: Curiosidades | Café Hondureño
Asignatura: Programación Web II - Grupo 2
============================================================

DESCRIPCIÓN DE LA ACTIVIDAD
Utilización de un modelo de lenguaje de IA como herramienta de apoyo
para el desarrollo, optimización y revisión de una página web
(HTML5, CSS3 y JavaScript) con curiosidades del café hondureño.


------------------------------------------------------------
FASE 1: CONTENIDO Y ESTRUCTURA
------------------------------------------------------------
PROMPT:
"Necesito una página web en HTML5 con curiosidades del café
hondureño, organizadas en cuatro temas: economía, historia,
cultivo y cultura. Dame datos basados en el Instituto Hondureño
del Café (IHCAFE) y propón una estructura semántica con
encabezado, portada, secciones y pie de página."

APORTE DE LA IA:
Propuesta de estructura semántica (header, main, section, footer)
y de un conjunto de curiosidades clasificadas por tema.


------------------------------------------------------------
FASE 2: ESTILOS CSS Y DISEÑO VISUAL
------------------------------------------------------------
PROMPT:
"Crea el CSS con variables (:root) usando una paleta de tonos
café, tipografías Playfair Display para títulos y Poppins para el
texto, y un color distinto para cada tema. Agrega un modo oscuro
automático con prefers-color-scheme."

APORTE DE LA IA:
Variables CSS para la paleta, integración de Google Fonts, colores
por tema y modo oscuro automático con prefers-color-scheme.


------------------------------------------------------------
FASE 3: DISEÑO RESPONSIVE
------------------------------------------------------------
PROMPT:
"Muestra las curiosidades en una cuadrícula con CSS Grid
(repeat(auto-fill, minmax(310px, 1fr))) que se adapte a celulares
con @media queries, sin usar Bootstrap. Usa clamp() para que los
títulos escalen."

APORTE DE LA IA:
Cuadrícula adaptable con CSS Grid, tamaños de título fluidos con
clamp() y reglas @media (max-width: 600px) para pantallas pequeñas.


------------------------------------------------------------
FASE 4: JAVASCRIPT - CURIOSIDAD ALEATORIA
------------------------------------------------------------
PROMPT:
"Haz un botón que muestre una curiosidad aleatoria en la portada
sin repetir la anterior, con una transición de opacidad al
cambiar. Guarda los datos en un arreglo de objetos con tema,
ícono, título y texto."

APORTE DE LA IA:
Función mostrarAleatoria() que evita repetir la curiosidad
anterior y aplica una transición de opacidad al cambiar el
contenido.


------------------------------------------------------------
FASE 5: JAVASCRIPT - FILTROS POR TEMA
------------------------------------------------------------
PROMPT:
"Genera dinámicamente botones de filtro (Todas, Economía,
Historia, Cultivo, Cultura) y haz que la lista de tarjetas se
actualice al seleccionar uno, con un borde de color según el
tema."

APORTE DE LA IA:
Creación dinámica de botones de filtro, función pintarLista() que
filtra el arreglo de curiosidades y renderiza las tarjetas con el
color de su tema.


------------------------------------------------------------
FASE 6: JAVASCRIPT - SECCIÓN "¿MITO O REALIDAD?"
------------------------------------------------------------
PROMPT:
"Crea una sección interactiva donde cada afirmación sea un botón
que, al tocarlo, despliegue la respuesta y diga si es mito o
realidad, usando un arreglo de objetos con esReal y resp."

APORTE DE LA IA:
Función crearMitos() que genera botones desplegables y muestra el
veredicto (Mito o Realidad) junto con la explicación.


------------------------------------------------------------
FASE 7: ACCESIBILIDAD
------------------------------------------------------------
PROMPT:
"Mejora la accesibilidad: usa aria-live, aria-pressed y
aria-expanded donde corresponda, agrega :focus-visible para la
navegación con teclado y respeta prefers-reduced-motion
desactivando las animaciones."

APORTE DE LA IA:
Atributos ARIA en los componentes interactivos, estilo de foco
visible para teclado y desactivación de animaciones para usuarios
que lo prefieran.


------------------------------------------------------------
FASE 8: REVISIÓN
------------------------------------------------------------
PROMPT:
"Revisa mi código HTML, CSS y JS, corrige errores y verifica que
los datos del café (cifras de exportación, altitudes, fechas)
sean coherentes con las fuentes citadas."

APORTE DE LA IA:
Revisión general del código y sugerencias de corrección y de
verificación de datos contra fuentes oficiales (IHCAFE).
