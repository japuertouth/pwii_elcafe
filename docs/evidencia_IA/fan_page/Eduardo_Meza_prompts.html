Evidencia de Uso de Inteligencia Artificial (IA)

Descripción de la actividad: Utilización de un modelo de lenguaje de IA como herramienta de apoyo para el desarrollo, optimización y refactorización de código front-end (HTML5, CSS3 y JavaScript).

1. Interacción para el Rediseño y Mejora Visual

Prompt (Solicitud): "Mejora este código, agrega CSS y JS para que se vea más estético y con mejoras."

Resultado / Aporte de la IA: Rediseño completo de la interfaz de usuario (UI), integración de variables CSS, Google Fonts, modo oscuro/claro interactivo y efectos visuales de transición.

Fase 2: Estilos CSS3 Pure, Flexbox y Responsive Design

Prompt / Consulta del Usuario: "¿Cómo puedo alinear los elementos de la galería y la sección de noticias usando únicamente Flexbox y CSS Vanilla, asegurando que sea adaptable a móviles con @media queries sin usar Bootstrap?"
Respuesta / Asistencia de la IA: Generó el código CSS definiendo contenedores flexibles (`display: flex; flex-wrap: wrap;`) y las reglas responsive con Media Queries (`@media (max-width: 768px)`) para transformar las distribuciones horizontales a columnas verticales en pantallas pequeñas.
